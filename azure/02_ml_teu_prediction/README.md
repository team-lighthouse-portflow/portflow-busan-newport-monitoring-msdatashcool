# 부산신항 부두별 물동량 예측 머신러닝 프로젝트

본 프로젝트는 부산신항 1부두부터 7부두까지의 선석 배정 및 조업 실적 데이터, SCFI 운임 지수, 그리고 월별 확정 환적비 데이터를 활용하여 향후 18개월(2026년 하반기 ~ 2027년) 동안의 월별 컨테이너 물동량(TEU)을 예측합니다. 향후 측정된 월별데이터로 연보고서에 연단위 물동량 예측을 적을 수 있습니다.

---

## 📌 주요 특징 및 기능

1. **하이브리드 샘플링 아키텍처**
    - 데이터 변동성이 극심한 **3부두**는 초고해상도인 **2주 단위(Bi-weekly, 연 26주기)**로 모델링 후 월간으로 합산(Roll-up)하여 오차를 기존 대비 약 68.5% 개선했습니다.
    - 나머지 **1, 2, 4, 5, 6, 7부두**는 표준 **월 단위(Monthly)** 예측 트랙으로 동작합니다.
        - 데이터가 똑같이 적었던 6,7부두는 2주 단위  하지 않은 이유 : 최근에 오픈해서 계속해 성장하고 있는 부두라 변동성이 크다. 2주 단위로 했을때 모델 지표가 **낮고**, 오히려 잘 학습하지 못했음
2. **물리적 선석 점유율(컬럼명 : BerthOccupancy) 병합**
    - 선석 일정의 겹침(Overlap) 구간을 하나로 압축 병합하는 그리디 알고리즘을 사용해 중복 가동 시간의 집계를 원천적으로 차단합니다(큰 선석에 작은 배들이 두 개씩 들어올 경우 배 기준으로 구할 때 선석 점유율이 100%가 넘게 되는 문제 방지).
    - 7부두의 경우 데이터 부족으로 인해 특정 월의 조업 데이터 누락 시 훈련 드롭이 될 수 있습니다. 방지하기 위해 **점유율 보완 로직**이 탑재되어 있습니다.
3. **데이터 브릭스 전용** 
    - **ADLS Gen2 (Azure Blob Storage) 연동**
    - **MLflow Tracking 및 모델 레지스트리**

## 🔍 독립변수 (11대 Features) 명세서

예측 파이프라인 학습에 입력되는 11대 핵심 독립변수들의 개념과 추출 및 보정 산식입니다.

| 독립변수명 (Feature) | 변수 개념 및 중요성 (Concept) | 추출 과정 및 계산 공식 (Formula / Logic) |
| --- | --- | --- |
| **`Weight`** | 항만 업황 특유의 월별 성수기(5월) 및 비수기(8월) 등 주기적이고 반복적인 계절성(Seasonality) 패턴을 고정 상수 형태로 보정합니다. | 22~25년 월별 총물동량 데이터의 월별 평균을 구한 뒤, 전체 월평균으로 나누어 지수화합니다. (기준값 = 1.0) |
| **`SCFI_MoM`** | 상하이 컨테이너 운임비 지수 : 글로벌 해상 물류 정세, 공급망 병목 및 운임 변동성(국제 정세의 대리 변수)을 지수 변동량 형태로 반영합니다. | 주간 단위의 SCFI 지수를 월평균으로 묶은 후, 전월 대비 등락율(MoM %)을 계산합니다. |
| **`BerthOccupancy`** | 선석 포화 상태를 변수화하여 계산 | $Occupancy = \frac{\text{24시간 병합된 실제 점유 시간} \times 100}{\text{선석 수} \times \text{한 달 일수} \times 24}$
※ 예측 시: $\text{전년 동월 Occupancy} \times \text{최신 3개월 추세 배율}$ |
| **`Lag12_Adj`** | 작년 같은 달 물동량 값. 스케일을 유지하고 시계열 예측이 평균값으로 수렴하여 평탄화되는 것을 방지합니다. | 전년도 동월 실적 물동량 $\times$ 최근 3개월 추세 배율*(3부두의 경우 전년 26주기 전 실적 사용)* |
| **`RollingAvg3_YoY`** | 전년도 월별 물동량의 3개월 이동평균으로, 단기 노이즈에 왜곡되지 않는 항만의 중장기 볼륨 수준(Level)을 학습합니다. | 전년도 동월 $t$ 기준 $[t-1, t, t+1]$ 3개월 물동량의 이동평균 |
| **`TransshipmentRatio`** | 환적량 처리 비율 | $\text{환적 비중} = \frac{\text{환적수량 합계}}{\text{전체물동량}} \times 100$※ 예측 시: $\text{전년 동월 환적 비중} \times \text{최근 3개월 변화량}$ |
| **`VesselCount`** | 월간 기항 선박의 총 척수로, 항만 활동의 물리적 빈도와 물동량 스케일을 직접 매핑합니다. | 월별 고유 모선 기항 척수 카운트※ 예측 시: $\text{작년 동월 VesselCount} \times \text{최근 3개월 추세 배율}$ |
| **`AvgDwellTime`** | 선박의 평균 정박 시간으로, 항만의 실질 하역 효율성 및 병목 대기 지연 강도를 대변합니다. | $DwellTime = \text{출항예정일시} - \text{접안예정일시}$ (시간 단위 평균) ※ 예측 시: $\text{작년 동월 AvgDwellTime} \times \text{최근 3개월 추세 배율}$ |
| **`ShiftRatio`** | 전체 하역 물량 중 이적(Shifting) 화물의 비중. 조업 지연 대비 실질 처리량의 왜곡을 보정합니다. (주의: 이적 화물은 타깃 물동량에 미포함) | $ShiftRatio = \frac{\text{총 이적수량}}{\text{총 물동량}} \times 100$※ 예측 시: $\text{작년 동월 ShiftRatio} \times \text{최근 3개월 추세 배율}$ |
| **`Month_Sin`** | sin 삼각함수에서 2pi를 기준으로 12개의 지점을 나눠 각 지점을 각 월에 매핑.
이로서 12월에서 1월로 넘어가갈때 자연스럽게 이어지면서 계절 주기성을 학습할수 있음. | $\sin(2\pi \times \text{월}/12)$
*(3부두는  $\sin(2\pi \times \text{Biweek}/26)$)* |
| **`Month_Cos`** | 삼각함수의 코사인 성분으로, 사인 피처와 위상이 대칭되는 순환 보조 변수 역할을 수행합니다. | $\cos(2\pi \times \text{월}/12)$
*(3부두는 $\cos(2\pi \times \text{Biweek}/26)$)* |

## 📊 모델 설계 및 앙상블 기법 설계 의도 (Modeling Rationale)

본 예측 시스템은 **XGBoost Regressor**와 **Ridge Regression** 모델을 **5:5 가중치로 결합한 하이브리드 앙상블 모델**을 채택하고 있습니다. 이 모델의 설계 의도는 다음과 같은 기계학습적 문제를 해결하기 위함입니다.

### 1) 트리 모델의 외삽(Extrapolation) 한계 극복

- **문제점**: XGBoost와 같은 트리 기반 모델은 분할 임계값에 따라 리프 노드의 타깃 평균값으로 예측을 수행하므로, **훈련 데이터 범위 내의 Target ($y$) 최댓값 이상 혹은 최솟값 이하를 예측할 수 없는 태생적 한계**를 가집니다. 즉, 항만 물동량이 과거 범위를 초과하여 지속적으로 성장하는 선형적 트렌드를 추종할 수 없습니다.(단, 하이퍼파라미터 튜닝 등을 통해 트리 특성을 바꿔주면 XGBoost도 선형적 트렌드 학습 가능. 대신 **트리 모델로서의 특징을 잃음.**)
- **해결책**: L2 규제가 적용된 선형 모델인 **Ridge Regression**을 앙상블에 병렬 배치하여, 피처 트렌드에 따른 선형적 외삽(Linear Extrapolation) 능력을 탑재하고 장기 시계열 성장을 포착할 수 있도록 보완했습니다.

### 2) 얕은 트리 분할로 인한 피처 중요도 편중 차단

- **문제점**: 시계열 물동량 예측에서는 Target의 1년 전 실적인 `Lag12_Adj` 피처가 **압도적으로 높은 상관관계**를 지닙니다. XGBoost가 루트 및 주요 분할 노드에서 오직 `Lag12_Adj` 피처만 선택하게 됩니다. 이 경우 피처 중요도가 단 한 개에만 과도하게 쏠려, SCFI 운임 지수나 선석 점유율 등 최신 조업 신호들이 전혀 반영되지 못하는 둔감한 모델이 됩니다. 트리를 학습시킬 때 깊이를 얕게 설정할 수도 없는 것이, 데이터의 **개수가 너무 적기**에 **트리 분할을 최대한 적게** 해야 과적합을 피할 수 있었습니다. (본 모델 규격 `max_depth=3`),
- **해결책**: 가중치 감쇄(Weight Decay) L2 규제 패널티를 가진 **Ridge Regression**을 융합함으로써, 모델이 하나의 지배적인 변수에만 가중치를 몰아주지 못하도록 강제하고, 상관성이 높은 여러 조업 변수들에 가중치를 고르게 분산(Weight Distribution)시켰습니다.

## 🚀 사용 방법 (Databricks)

1. 데이터브릭스 워크스페이스 내에 `databricks_예측.py` 노트북 파일을 업로드합니다.
2. 노트북 상단에 노출되는 두 가지의 **Widgets** 입력 값을 지정합니다:
    - `container`: SCFI지수 및 환적비 파일이 적재된 메인 컨테이너명 (기본값: `"container-operation"`)
    - `container2`: 부두별 원시 엑셀 데이터 파일들이 적재된 원시 컨테이너명 (기본값: `"raw"`)
3. **Run All**을 클릭해 실행합니다.
    - 실행 완료 시 부두별 미래 18개월 예측 물동량 요약 테이블과 그래프가 시각화되며, `port_cargo_forecast_cyclical` MLflow 실험에 모든 파라미터와 아티팩트가 자동 트래킹됩니다.
